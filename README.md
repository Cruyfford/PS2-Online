# PS2 Online — Cruyfford

برنامج للعب ألعاب **بلايستيشن 2** أونلاين بين جهازين على شبكات مختلفة، بدون فتح منافذ. يعمل على **Windows**.

- كل لاعب يشغّل المحاكي (نواة **LRPS2** = `pcsx2_libretro`) على جهازه، فلا يوجد بث فيديو.
- المزامنة تتم بالأزرار فقط (lockstep) عبر **نفس سيرفر SNES Online** على Cloudflare.
- **حساب مطلوب:** نفس حساب SNES Online و PS1 Online.
- قائمة اللاعبين والتحدي والرسائل الخاصة والمكالمات الصوتية تعمل كما في SNES Online. القائمة تعرض لاعبي PS2 فقط.
- **المضيف يحدد إعدادات المحاكي** (المحاكاة الرسومية والدقة)، والضيف يأخذها منه تلقائياً، وكذلك بطاقة الذاكرة.

## 1) التجهيز (عند كل لاعب)

```bash
pip install PySide6 websockets
pip install pygame          # اختياري: لدعم يد التحكم
```

1. حمّل **PS2-Online-PC.zip** من صفحة Releases وفكّه. يأتي مع `client/cores/pcsx2_libretro.dll`.
2. **البايوس (إلزامي):** ضع ملف بايوس PS2 (مثل `SCPH-70012.bin`) في `client/system/pcsx2/bios/`. من الإعدادات يوجد زر 📁 يفتح المجلد.
3. شغّل البرنامج بـ `run.bat`.

**يجب أن يتطابق عند اللاعبين:**

| الشيء | ملاحظة |
|---|---|
| حزمة PS2-Online-PC | نفس الإصدار، لأن نسخة النواة يجب أن تكون واحدة |
| ملف اللعبة | نفس ملف ISO/CHD بالضبط، ونفس الباتش إن وُجد |
| البايوس | نفس الملف بالضبط. اسم الملف يمكن أن يختلف |

البرنامج يتحقق من الثلاثة تلقائياً، ويعرض رسالة واضحة إذا اختلف أحدها.

## 2) اللعب

1. اختر ملف اللعبة: `.iso` أو `.chd` أو `.cso` أو `.zso` أو `.gz`.
2. **المضيف** (الكنترول الأول): يضغط "إنشاء غرفة" ويرسل الكود لصديقه، أو يتحداه مباشرة من صفحة **اللاعبون**.
3. **الضيف** (الكنترول الثاني): يكتب الكود ويضغط "انضمام".
4. المضيف يرسل للضيف الإعدادات وبطاقة الذاكرة وحالة اللعبة، ثم تبدأ المباراة.
   - حالة لعبة PS2 كبيرة، حوالي 10–30MB بعد الضغط، وإرسالها يأخذ عدة ثوانٍ حسب سرعة رفع المضيف.
   - يمكن للضيف الخروج والعودة، وستتم المزامنة من جديد.

### الإعدادات

| الإعداد | الوصف |
|---|---|
| **المحاكاة الرسومية** | **المعالج (Software)**: الافتراضي والأضمن للأونلاين، لأن الصورة تُحسب بنفس الطريقة على أي جهازين. يحتاج معالجاً قوياً، 6 أنوية أو أكثر. **كرت الشاشة (OpenGL)**: أسرع ويدعم دقة 2x و4x. لكن في ألعاب قليلة تقرأ الصورة من كرت الشاشة، قد يحدث desync إذا كان كرتا الشاشة عند اللاعبين مختلفين. |
| **تأخير المدخلات** | الافتراضي 3 إطارات. إذا كان البنق أعلى من 100ms ارفعه إلى 4 أو 5. |
| **بطاقة الذاكرة** | المضيف يحفظ في `saves/<اسم اللعبة>.ps2`. الضيف يستلم نسخة من بطاقة المضيف في `saves/netplay/`، فلا تضيع بطاقته الأصلية. |

## 3) إضافات العرض (plugins/)

ضع ملف `.py` في `client/plugins/` يعرّف `PLUGIN`. انظر `_example_view.py`.

- الدالة `overlay(painter, rect, ram, player)` ترسم فوق الصورة.
- `ram` هي ذاكرة PS2 الرئيسية بحجم 32MB، والفهرس 0 يقابل العنوان `0x00000000`.
- `player` يساوي 0 للمضيف و1 للضيف.

## التحكم في الكمبيوتر

| زر PS2 | المفتاح |
|---|---|
| الأسهم | الأسهم |
| ✕ / ○ / □ / △ | Z / X / A / S |
| L1 / R1 | Q / W |
| L2 / R2 | E / R |
| L3 / R3 | C / V |
| العصا اليسرى | I J K L |
| العصا اليمنى | 8 4 5 6 |
| Start / Select | Enter / Shift |

- يد Xbox أو PlayStation تعمل تلقائياً إذا كانت مكتبة `pygame` مثبتة، مع العصا التناظرية والزنادين.
- **T**: دردشة. **M**: كتم الميكروفون. **- و =**: صوت المحادثة. **F11**: ملء الشاشة. **Esc**: خروج.

## 4) أغلفة الألعاب على السيرفر

لكي تظهر أغلفة ألعاب PS2، أضف `server/ps2_index.js` وتعديل `server/cover.js`، وكلاهما موجود في `server-patch/`، إلى مستودع SNES-Online. بعدها نفّذ:

```bash
cd server
wrangler deploy
```

بقية السيرفر (الغرف والحسابات واللاعبون) يعمل بدون أي تعديل.

## ملاحظات

- إذا ظهرت رسالة **«عدم تطابق (desync)»**، اخرج من الغرفة وادخل من جديد لتتم المزامنة مرة أخرى. إذا تكرر ذلك مع لعبة معينة باستخدام OpenGL، استخدم **المعالج (Software)**.
- البرنامج يجبر بعض إعدادات النواة على قيم ثابتة لأنها ضرورية للتزامن: MTVU مغلق، سرعة EE 100%، والغش وباتشات الشاشة العريضة مغلقة.
